# NovaTech Store — Loja Fictícia

Projeto prático desenvolvido como atividade final do curso de **Bootstrap 5** (Cursa),
aplicando os principais conceitos estudados ao longo das 17 aulas.

## 📄 Descrição

Página de e-commerce fictício (NovaTech Store) com vitrine de produtos de tecnologia,
categorias, tabela de opções de frete e formulário de contato, totalmente responsiva.

## 🛠️ Componentes e recursos do Bootstrap 5 utilizados

- **Grid System** (`.row` / `.col-*`): estrutura responsiva em todas as seções.
- **Navbar** (Aula #16): menu fixo com colapso em mobile e botão de carrinho.
- **Cards** (Aula #12): vitrine de 6 produtos com preço, badge de desconto/novo e botão.
- **Botões** (Aula #07): CTAs no Hero e botões "Adicionar" nos produtos.
- **Formulário** (Aula #06): seção de contato com campos, select e textarea.
- **Tabela** (Aula #10): comparativo de planos de frete.
- **Imagens** (Aula #09): uso de `img-fluid` para responsividade.
- **Tipografia** (Aula #08): `display-3`, `lead`, `fw-bold`, `text-uppercase`.
- **Cores** (Aula #02): `bg-dark`, `bg-light`, `text-info`, badges coloridos.
- **Spacing** (Aula #05): `py-5`, `mb-4`, `mt-4`, `g-4`, etc.
